# Organización del frontend

Cada microservicio tiene una carpeta independiente:

```text
microservicios/
├── microservicio-1/
├── microservicio-2/
├── microservicio-3/
├── microservicio-4/
└── microservicio-5/
```

El panel general, los estilos y los componentes reutilizables permanecen fuera de estas carpetas. Cada integrante debe modificar únicamente la carpeta de su microservicio y reutilizar las clases CSS existentes.
