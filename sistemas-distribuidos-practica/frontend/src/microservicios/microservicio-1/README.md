# Microservicio 1

Esta carpeta contiene la interfaz del control de acceso al estacionamiento.

## Responsable

El integrante asignado al Microservicio 1 trabaja aquí sin modificar el panel general.

## Componente

- `EstacionamientoPanel.jsx`: simulación, espacios, vehículos, cola de espera y acciones.

## API

Las llamadas al Gateway están centralizadas en:

```text
src/services/microserviciosApi.js
```

No se deben modificar los estilos globales para personalizar este componente.
